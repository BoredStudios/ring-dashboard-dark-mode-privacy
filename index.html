Privacy Policy for Ring Dashboard Dark Mode

Effective date: September 21, 2026

Ring Dashboard Dark Mode is a browser extension that applies a user-controlled dark theme to supported Ring account pages.

Data collection and use

The extension does not collect, transmit, sell, share, or store personal information, authentication information, financial information, location information, browsing history, user activity, camera footage, video, recordings, or account content.

The extension stores one preference locally in the browser: whether the dark theme is enabled. This preference is used only to apply or remove the theme. It is not sent to any server or third party.

Third parties and tracking

The extension does not use analytics, advertising, tracking, remote code, or external services. It does not make network requests.

Website access

The extension runs only on supported Ring account pages to apply its bundled styles. It does not extract or retain page content, account information, camera footage, or recordings.

Changes to this policy

If this policy changes, the updated version will be published at this address with a revised effective date.

Contact

For questions about this policy, please open an issue in the GitHub repository where this policy is published.
